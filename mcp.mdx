The Model Context Protocol (MCP) lets external AI assistants, IDEs, and agentic workflows connect directly to Attlas.

Whether you want to let external tools query a public chat's knowledge base or give an AI assistant full control over your workspace, Attlas provides dedicated MCP endpoints with 55 tools for workspace management and 2 tools for public chat knowledge retrieval.

Choose an entry point below to get started:

<Card title="Workspace MCP" icon="server" href="/mcp/workspace">
  Connect external tools like Claude Code, Cursor, Claude Desktop, and VS Code to manage your entire workspace using private API keys (55 tools).
</Card>

<Card title="Chat MCP" icon="message-square" href="/mcp/chat">
  Allow external AI tools to query your public chat's knowledge base directly without requiring an account or API key (2 tools).
</Card>
