L'agent est une conversation intégrée à votre tableau de bord. Vous tapez une demande en langage courant, et il lit les données de votre chat ou modifie le chat pour vous.

Par exemple, vous pouvez demander :

- "Combien de visiteurs mon chat a-t-il reçus cette semaine, et d'où venaient-ils ?"
- "À quelles questions mon chat a-t-il mal répondu ?"
- "Ajoute trois questions suggérées concernant mes horaires d'ouverture."
- "Passe à un thème plus sombre."

<Note>
  Chaque demande que vous envoyez à l'agent utilise un **message d'agent**. Votre formule inclut une allocation mensuelle :

  | Formule | Messages d'agent par mois |
  |---|---|
  | Gratuite | 20 |
  | Starter | 100 |
  | Pro | 300 |

  Lorsque vous avez épuisé votre quota, l'agent cesse de répondre jusqu'au renouvellement de votre allocation. Vous pouvez changer de formule pour en obtenir davantage.
</Note>

---

## Ouvrir l'agent

1. Ouvrez l'un de vos chats dans le tableau de bord.
2. Cliquez sur **Agent** dans la barre supérieure. Sur mobile, appuyez sur le bouton rond **Agent** en bas de l'écran.

L'agent travaille sur le chat que vous avez ouvert. L'aperçu de votre chat reste visible sur la droite, vous voyez donc chaque modification dès qu'elle est appliquée.

<Info>
  Seuls les membres de votre espace de travail peuvent utiliser l'agent. Un membre avec le rôle **Lecteur** peut poser des questions mais ne peut rien modifier.
</Info>

---

## Commencer par vos améliorations principales

Lorsque vous ouvrez une nouvelle conversation, l'agent affiche les **Améliorations principales** : les trois éléments les plus utiles manquant à votre chat, comme des connaissances, un message d'accueil ou des questions suggérées. Vous voyez également votre taux de couverture et le nombre de prospects des 30 derniers jours.

Cliquez sur une amélioration et l'agent vous guide pas à pas, une question à la fois.

## Choisir comment les modifications sont appliquées

Le sélecteur de mode se trouve dans la zone de saisie du message.

| Mode | Ce qui se passe |
|---|---|
| **Manuel** (par défaut) | L'agent affiche chaque modification sur une carte. Vous cliquez sur **Appliquer** pour l'effectuer, ou sur **Refuser** pour l'ignorer. |
| **Auto** | L'agent applique les modifications immédiatement et affiche une carte pour chacune d'elles. |

<Warning>
  L'agent ne supprime jamais rien, quel que soit le mode. Pour supprimer un déclencheur, un document ou un contact, utilisez l'écran correspondant dans le tableau de bord.

  En mode **Auto**, le texte écrit par vos visiteurs ou trouvé dans vos documents peut orienter une modification que vous n'aviez pas demandée. Restez en mode **Manuel** si vous souhaitez vérifier chaque modification au préalable.
</Warning>

## Ce que l'agent peut faire

| Lire | Modifier |
|---|---|
| Visites, prospects et chiffres de conversion | Questions suggérées (déclencheurs) : ajouter, modifier, réorganiser, grouper |
| Conversations des visiteurs | Thème, image de marque, avatar et liens sociaux |
| Contacts et rendez-vous | Objectif et personnalité |
| Questions auxquelles votre chat a mal répondu | Infos sur l'entreprise, description, message d'accueil et SEO |
| Documents de connaissance | Connaissances : ajouter un lien ou un fichier, rédiger un document, ajouter une correction, nettoyer un document |
| Rapports | Générer un nouveau rapport |

L'agent peut également vous conseiller : quelle fonctionnalité correspond à votre objectif, comment organiser vos connaissances, quelles questions vos visiteurs attendent.

Certains paramètres restent dans le tableau de bord. L'agent vous indique l'écran approprié lorsque vous demandez :

- la suppression de quoi que ce soit,
- la modification de l'URL de votre chat,
- la connexion d'une intégration (Google Calendar, Notion, une base de données, un domaine personnalisé, un webhook),
- le mode d'accès, le mot de passe ou la visibilité,
- votre formule, la facturation et les membres de l'espace de travail.

## Joindre des fichiers et des images

Cliquez sur le bouton de pièce jointe dans la zone de saisie du message pour ajouter jusqu'à 5 fichiers. L'agent lit les PDF et les images (PNG, JPEG, WebP, GIF) pour vous répondre. Demandez-lui d'ajouter un fichier à vos connaissances et il l'importe de la même manière que la fenêtre [Sources](/fr/start/sources). Les fichiers audio sont décomptés de votre quota de la même façon également.

---

## Recherche sur le Web

L'agent peut effectuer des recherches sur le Web, par exemple pour vérifier vos horaires d'ouverture sur une fiche publique. Il affiche les sources qu'il a utilisées sous sa réponse.

Une fois que l'agent a effectué une recherche sur le Web dans une conversation, chaque modification attend que vous cliquiez sur **Appliquer**, même en mode **Auto**.

<Tip>
  Vous pouvez également piloter votre espace de travail depuis Claude, Cursor ou un autre assistant IA, avec les mêmes actions et conseils. Consultez [Workspace MCP](/fr/mcp/workspace).
</Tip>
