Le Model Context Protocol (MCP) permet aux assistants IA externes, aux IDE et aux flux de travail agentiques de se connecter directement à Attlas.

Que vous souhaitiez permettre à des outils externes d'interroger la base de connaissances d'un chat public ou donner à un assistant IA le contrôle total de votre espace de travail, Attlas fournit des points de terminaison MCP dédiés avec 55 outils pour la gestion de l'espace de travail et 2 outils pour la récupération des connaissances du chat public.

Choisissez un point d'entrée ci-dessous pour commencer :

<Card title="Workspace MCP" icon="server" href="/fr/mcp/workspace">
  Connectez des outils externes tels que Claude Code, Cursor, Claude Desktop et VS Code pour gérer l'ensemble de votre espace de travail à l'aide de clés API privées (55 outils).
</Card>

<Card title="Chat MCP" icon="message-square" href="/fr/mcp/chat">
  Autorisez les outils d'IA externes à interroger directement la base de connaissances de votre chat public, sans nécessiter de compte ni de clé API (2 outils).
</Card>
