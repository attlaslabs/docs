Les clés API d'Espace de travail permettent aux outis de dévelopement externes et aux assistants IA (Claude Code, Cursor, Claude Desktop, VS Code et Codex) de se connecter à l'ensemble de votre espace de travail Attlas en utilisant le Model Context Protocol (MCP).

Contrairement au point de terminaison MCP de chat public, les clés API d'Espace de travail sont des identifiants privés avec périmètre qui couvrent tous les chats, documents de connaissances, déclencheurs, contacts et analyses de votre espace de travail.

<Tip>
  Votre assistant sait déjà comment configurer et améliorer un chat Attlas. Demandez « aide-moi à configurer mon chat » ou « que devrais-je ajouter à mon chat commercial » et il vous guide pas à pas. Rien à installer.
</Tip>

## Démarage rapide

Connectez votre assistant IA à votre espace de travail Attlas en trois étapes :

<Steps>
  <Step title="Créez une clé API">
    1. Dans le tableau de bord Attlas, ouvrez **Paramètres de l'espace de travail**.
    2. Allez dans l'onglet **Clés API** (ou **MCP**).
    3. Cliquez sur **Créer une clé API**.
    4. Saisissez un nom (par ex. `Cursor assistant` ou `Claude Code`).
    5. Choisissez vos autorisations (**Écrire** pour créer et modifier des ressources, ou **Supprimer** si vous avez besion de privilèges de suppression).
    6. Cliquez sur **Créer la clé** et copiez votre clé secrète (`atk_...`) immédiatement.

    <Warning>
      Votre clé API n'est affichée qu'une fois. Conservez-la en lieu s\u00fbr. Attlas ne pourra plus l'afficher une fois la bo\u00eete de dialogue fermée.
    </Warning>
  </Step>

  <Step title="Configurez votre client IA">
    Le point de terminaison MCP d'Espace de travail est hébergé à l'adresse :
    ```text
    https://mcp.attlas.so
    ```

    Séléctionnez votre outil IA ci-dessous pour copier la commande d'installation ou le fichier de configuration :

    <CodeGroup>

    ```bash Claude Code
    claude mcp add attlas --transport http https://mcp.attlas.so \
      --header "Authorization: Bearer atk_your_api_key"
    ```

    ```json Cursor
    {
      "mcpServers": {
        "attlas": {
          "url": "https://mcp.attlas.so",
          "headers": {
            "Authorization": "Bearer atk_your_api_key"
          }
        }
      }
    }
    ```

    ```json Claude Desktop
    {
      "mcpServers": {
        "attlas": {
          "command": "npx",
          "args": [
            "mcp-remote",
            "https://mcp.attlas.so",
            "--header",
            "Authorization: Bearer atk_your_api_key"
          ]
        }
      }
    }
    ```

    ```json VS Code
    {
      "servers": {
        "attlas": {
          "type": "http",
          "url": "https://mcp.attlas.so",
          "headers": {
            "Authorization": "Bearer atk_your_api_key"
          }
        }
      }
    }
    ```

    ```toml Codex
    [mcp_servers.attlas]
    command = "npx"
    args = [
      "mcp-remote",
      "https://mcp.attlas.so",
      "--header",
      "Authorization: Bearer atk_your_api_key"
    ]
    ```

    </CodeGroup>

    <Tip>
      Si vous utilisez **Cursor**, cliquez sur le bouton **Add to Cursor** directement dans l'onglet Clés API d'Attlas pour configuer la connexion en un seul clic.
    </Tip>
  </Step>

  <Step title="Vérifiez la connexion">
    Testez votre configuration en demandant à votre assistant :
    ```text
    List my Attlas chats
    ```
    Votre assistant appellera l'outil `list_chats` et renverra la liste des chats avec leurs identifiants numériques.
  </Step>
</Steps>

## Claude web et bureau (connecteur personnalisé)

Pour vous connecter depuis claude.ai ou l'application de bureau Claude, ajoutez Attlas en tant que **connecteur personnalisé**. Le point de terminaison de l'espace de travail s'autentifie avec une clé API, pas OAuth ; quelues champs nécessitent donc des valeurs spécifiques.

<Steps>
  <Step title="Ouvrez la boîte de dialogue du connecteur personnalisé">
    Dans Claude, accédez à **Paramètres → Connecteurs → Ajouter un connecteur personnalisé** (Équipes et Entreprise : **Paramètres de l'organisation → Connecteurs → Ajouter → Personnalisé**).
  </Step>
  <Step title="Saisissez l'URL">
    ```text
    https://mcp.attlas.so
    ```
  </Step>
  <Step title="Définissez Authentification sur Aucune">
    Après avoir continué, Claude sonde l'URL et peut présélectioner **Toujours requise**, marquée *Détectée*. Il s'agit d'un faux positif : le serveur renvoie `401` à la sonde non authentifiée, et Claude interprète cela comme OAuth. Choisissez **Aucune** à la place. La description de cette option le dit explictement : *« ou pour les serveurs qui utilisent une clé API plutôt qu'OAuth. »* La section **Client OAuth** disparaît alors.
  </Step>
  <Step title="Ajoutez la clé comme en-tête de requèe">
    Ouvrez **En-têtes de requèe** et ajoutez un en-tête :

    | Champ | Valeur |
    | --- | --- |
    | Nom | `authorization` (sélectionnez-le dans la liste ; la minucule est acceptée, les noms d'en-tête HTTP sont insensibles à la casse) |
    | Valeur | `Bearer atk_your_api_key` |
    | Requis | coché |

    <Warning>
      Saisissez la valeur **exactement** comme le serveur l'attend, y compis le mot `Bearer` et un espace avant la clé. Claude envoie la valeur telle quelle et n'ajoute aucun schéma. La valeur `atk_...` seule est envoyée comme `Authorization: atk_...` et le serveur la rejette avec une `401`.
    </Warning>
  </Step>
  <Step title="Ajoutez le connecteur">
    Cliquez sur **Ajouter**, puis activez Attlas depuis le menu **+** dans une conversation.
  </Step>
</Steps>

<Note>
  **En-têtes de requèe** est une fonctionnalité bêta disponible pour un ensemble limité d'organisations. Si vous ne voyez pas cette section, connectez-vous avec Claude Code ou `mcp-remote` à la place (voir [Démarage rapide](#démarage-rapide) ci-dessus).
</Note>

### Dépannage

| Symptôme | Cause | Correction |
| --- | --- | --- |
| La connexion échoue, Claude demande de se connecter avec OAuth | Authentification laissée sur **Toujours requise**, ou la valeur de l'en-tête manque le préfixe `Bearer ` | Supprimez le connecteur, rajoutez-le avec **Aucune** et une valeur `Bearer atk_...` correcte |
| `401` à chaque appel | Clé erronée, révoquée ou mal formée ; valeur envoyée sans `Bearer ` | Vérifiez la clé dans l'onglet **Clés API** d'Attlas ; rajoutez le connecteur avec la valeur exacte |
| Outis manquants après la connexion | Le périmètre de la clé ne les inclut pas | Créez une clé avec le périmètre **Écrire** ou **Supprimer** |
| Fonctionne dans Claude Code mais pas sur claude.ai | La fonctionnalité bêta des en-têtes de requèe n'est pas activée pour votre organisation | Utilisez Claude Code ou `mcp-remote`, ou contactez le support Claude pour demander l'accès |
| `429 Limite de débit dépassée` | Plus de 120 appels en une minute avec la même clé | Attendez le nombre de secondes indiqué dans l'en-tête `retry-after`, puis réessayez |

## Périmètres des autorisations

Lors de la création d'une clé API, séléctionnez les autorisations qui correspondent à votre cas d'usage :

| Périmètre | Libellé UI | Ce qu'il peut faire |
| --- | --- | --- |
| `read` | **Lire** | Consulter et rechercher chats, documents, déclencheurs, contacts, conversations et analyses. Inclus par défaut sur toutes les clés. |
| `write` | **Écrire** | Créer et mettre à jour les documents, corrections, déclencheurs, contacts, image de marque, avatar, SEO et paramètres des chats. Inclut automtiquement les autorisations de lecture. |
| `destructive` | **Supprimer** | Supprimer les chats, documents, déclencheurs, contacts et conversations. Les chats et les documents sont définitivement supprimés. Les déclencheurs et contacts restent 30 jours dans la corbeille, vous pouvez donc les restaurer. Inclut automtiquement les autorisations d'écriture et de lecture. |

<Warning>
  N'accordez l'autorisation **Supprimer** qu'à des flux de travail de confiance pour lesquels un nettoyage automatisé ou la suppression de ressources est explictement nécéssaire.
</Warning>

## Exigences du plan

Le serveur MCP d'Espace de travail fonctionne avec tous les plans. Quelques actions suivent les mêmes limites de plan que le tableau de bord :

| Action | Exigence |
| --- | --- |
| Créer un chat (`create_chat`) | Utilise un chat du quota de votre plan. Renvoie `quota_exceeded` lorsqu'il n'y en a plus. |
| Lire les métriues, tendances, classements ou générer un rapport | La péride ne remonte que jusqu'à la fenêtre d'historique de votre plan (Gratuit : 90 jours, Starter : 1 an, PRO : 2 ans). Les pérides plus larges sont réduites à cette fenêtre. |
| Ajouter un lien vidéo YouTube, Instagram, TikTok, Facebook ou X, ou un fichier audio, à une base de connaissances | Starter ou PRO. Les liens de pages Web fonctionnent avec tous les plans. |
| Retirer le badge de marque Attlas (`update_branding`) | Module complémentaire de marque. |
| Personnaliser les métadonnées SEO du chat (`update_seo`) | Starter ou PRO. |
| Modifier les paramètres de la base de données SQL connectée au chat | Starter ou PRO. |

<Tip>
  Votre assistant peut appeler `can_use` pour vérifier une action par rapport à votre plan, et `get_usage` pour voir vos chats, messages et caractères restants.
</Tip>

## Outis disponibles

Chaque outil nécessite le périmètre indiqué à côté. Une clé ne voit que les outis autorisés par son périmètre.

### Chats et configuration

| Outil | Périmètre | Action |
| --- | --- | --- |
| `list_chats` | Lire | Liste vos chats avec leurs identifiants. Votre assistant l'appelle en premier. |
| `get_chat_overview` | Lire | Toutes les informations d'un chat en une seule lecture, plus une liste classée des éléments manquants. |
| `get_chat_config` | Lire | Paramètres d'un chat : objectif, capture de leads, intégrations, avatar, SEO, informations sur l'entreprise. |
| `preview_chat` | Lire | Affiche un aperçu en direct du chat public. Les messages envoyés dans l'aperçu sont gratuits et ne sont pas comptabilisés dans les analyses. |
| `list_theme_presets` / `list_archetypes` | Lire | Les thèmes et personnalités parmi lesquels vous pouvez choisir. |
| `create_chat` | Écrire | Cré un nouveau chat. |
| `update_chat` | Écrire | Nom, description, message de bienvenue et onglet qui s'ouvre en premier. |
| `update_activity_profile` | Écrire | Informations sur l'entreprise : site web, e-mail, téléphone, adresse, horaires d'ouverture, entreprise ou personne. |
| `set_objective` | Écrire | Support, prise de rendez-vous ou capture de leads, plus vos propres instructions. |
| `set_personality` | Écrire | Ton de voix, ou une personnalité prête à l'emploi. |
| `update_theme` | Écrire | Couleurs et thème visuel. |
| `update_avatar` | Écrire | Avatar à partir d'une URL d'image ou d'un emoji. |
| `update_social_links` | Écrire | La rangée d'icônes sociales en bas du chat. |
| `update_seo` | Écrire | Titre méta, description méta et image de partage. |
| `update_branding` | Écrire | Affiche ou masque le badge « Propulsé par Attlas ». |
| `update_database_connection` | Écrire | Nom, description, devise et activation/désactivation d'une base de données SQL connectée. Les identifiants restent intacts. |

### Connaissances

| Outil | Périmètre | Action |
| --- | --- | --- |
| `list_documents` / `read_document` | Lire | Liste les documents d'un chat avec leur statut, ou lit un document en entier. |
| `create_document` | Écrire | Ajoute un document texte. |
| `ingest_url` | Écrire | Ajoute une page web, un lien vers un fichier ou une vidéo (YouTube, TikTok, Instagram, X). |
| `update_document` | Écrire | Modifie un document texte. Seule la différence de longueur est déduite de votre quota. |
| `clean_document` | Écrire | Reformate un document importé mal formaté. |
| `create_correction` | Écrire | Apprend au chat la bonne réponse à une question à laquelle il a mal répondu. |

<Info>
  L'ajout ou la modification de connaissances prend un instant. Ces outils répondent immédiatement avec un statut `processing`, et votre assistant vérifie `list_documents` jusqu'à ce que le document soit prêt.
</Info>

### Déclencheurs

| Outil | Périmètre | Action |
| --- | --- | --- |
| `list_triggers` | Lire | Liste les boutons, liens, médias, produits et questions d'un chat. |
| `create_trigger` / `update_trigger` | Écrire | Ajoute ou modifie un déclencheur. |
| `reorder_triggers` | Écrire | Modifie l'ordre et l'imbrication. |
| `generate_questions` | Écrire | Suggère des questions des visiteurs à partir de vos documents, sans rien créer. |
| `generate_and_nest` | Écrire | Génère des questions et les place sous un déclencheur en une seule étape. |

### Contacts et rendez-vous

| Outil | Périmètre | Action |
| --- | --- | --- |
| `list_contacts` | Lire | Liste les contacts capturés par vos chats, avec leur étape. |
| `list_appointments` | Lire | Liste les rendez-vous réservés. |
| `update_contact` | Écrire | Modifie l'étape d'un contact ou ses notes internes. |

### Analyses

| Outil | Périmètre | Action |
| --- | --- | --- |
| `get_metrics` | Lire | Messages, vues, clics, leads, conversion et couverture des connaissances, comparés à la période précédente. |
| `get_timeseries` / `get_rankings` | Lire | Activité dans le temps, et principaux déclencheurs, pays, appareils et canaux. |
| `list_signals` | Lire | Questions auxquelles votre chat n'a pas pu répondre, réponses négativement évaluées et visiteurs qui sont partis. |
| `list_conversations` / `read_conversation` | Lire | Conversations des visiteurs et leurs messages. |
| `list_reports` / `read_report` | Lire | Rapports déjà générés. |
| `generate_report` | Écrire | Rédige un rapport d'analyse pour une période. |

### Plan

| Outil | Périmètre | Action |
| --- | --- | --- |
| `get_usage` | Lire | Votre plan et les chats, messages et caractères restants. |
| `can_use` | Lire | Vérifie si votre plan autorise une action. |

### Suppression

| Outil | Périmètre | Action |
| --- | --- | --- |
| `delete_chat` | Supprimer | Supprime un chat et tout son contenu. Définitif. |
| `delete_document` | Supprimer | Supprime un document et restitue ses caractères. Définitif. |
| `delete_trigger` / `delete_contact` | Supprimer | Déplace un déclencheur ou un contact dans la corbeille pendant 30 jours. |
| `delete_conversation` | Supprimer | Masque une conversation partout. Vous ne pouvez pas la restaurer via MCP. |

## Ce qui reste dans le tableau de bord

Certains paramètres nécessitent que vous soyez sur [attlas.so](https://attlas.so). Votre assistant vous indique quand une demande concerne ces points :

- Modifier l'URL d'un chat.
- Connecter une intégration : Google Calendar, Notion, une base de données SQL, Bandsintown, un domaine personnalisé ou un webhook. Une fois connectée, votre assistant peut la configer et l'utiliser.
- Mode d'accès, mot de passe et visibilité publique ou privée.
- Plan, facturation et modules complémentaires.
- Membres de l'espace de travail et invitations.

## Surveillance de l'activité et journaux d'audit

Le tableau **Activité récente** en bas de l'onglet Clés API enregistre chaque appel MCP effectué vers votre espace de travail :

- **Quand** : Horodatge relatif de la demande.
- **Clé** : Préfixe de la clé utilisée (`atk_...`).
- **Outil** : L'outil MCP appelé (ex. `list_chats`, `create_document`, `delete_triger`).
- **Cible** : La ressource concernée par l'opération.
- **Résultat** : Badge de succès (`ok`) ou d'erreur.

Activez **Modifications uniquement** pour masquer les appels de lecture.

### Restaurer les éléments supprimés

Si un outil a supprimé un déclencheur ou un contact par erreur, cliquez sur **Restaure** dans sa ligne d'activité dans les 30 jours.
