O Model Context Protocol (MCP) permite que assistentes de IA externos, IDEs e fluxos de trabalho agentivos se conectem diretamente ao Attlas.

Seja para permitir que ferramentas externas consultem a base de conhecimento de um chat público ou dar a um assistente de IA controle total sobre o seu workspace, o Attlas oferece endpoints MCP dedicados com 55 ferramentas para gerenciamento de workspace e 2 ferramentas para recuperação de conhecimento do chat público.

Escolha um ponto de entrada abaixo para começar:

<Card title="MCP do Workspace" icon="server" href="/pt/mcp/workspace">
  Conecte ferramentas externas como Claude Code, Cursor, Claude Desktop e VS Code para gerenciar todo o seu workspace usando chaves de API privadas (55 ferramentas).
</Card>

<Card title="MCP do Chat" icon="message-square" href="/pt/mcp/chat">
  Permita que ferramentas de IA externas consultem a base de conhecimento do seu chat público diretamente, sem necessidade de conta ou chave de API (2 ferramentas).
</Card>
