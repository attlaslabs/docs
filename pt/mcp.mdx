O Model Context Protocol (MCP) permite que assistentes de IA externos, IDEs e fluxos de trabalho agentivos se conectem diretamente ao Attlas.

Seja para permitir que ferramentas externas consultem a base de conhecimento de um chat público ou dar a um assistente de IA controle total sobre o seu workspace, o Attlas oferece endpoints MCP dedicados e habilidades prontas.

Escolha um ponto de entrada abaixo para começar:

<Card title="MCP do Workspace" icon="server" href="/pt/mcp/workspace">
  Conecte ferramentas externas como Claude Code, Cursor, Claude Desktop e VS Code para gerenciar todo o seu workspace usando chaves de API privadas.
</Card>

<Card title="MCP do Chat" icon="message-square" href="/pt/mcp/chat">
  Permita que ferramentas de IA externas consultem a base de conhecimento do seu chat público diretamente, sem necessidade de conta ou chave de API.
</Card>

<Card title="Habilidades" icon="sparkles" href="/pt/mcp/skills">
  Instale habilidades de agente prontas que ensinam seu assistente de IA a automatizar tarefas complexas, desde a configuração do chat até a ingestão de conhecimento e criação de gatilhos.
</Card>
