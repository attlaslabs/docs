O Attlas foi criado para se conectar com o conteúdo, as ferramentas e as plataformas que você já utiliza.

Nesta seção, você encontrará guias detalhados para configurar e tirar o máximo proveito de cada integração disponível.

As integrações permitem ampliar as capacidades do seu chat, importar conhecimento de diferentes fontes e criar experiências ainda mais ricas para os seus usuários.

Aqui, você aprenderá a conectar plataformas, configurar recursos específicos e usar cada integração de forma eficaz.

Escolha uma integração abaixo para acessar o guia de configuração e uso.
