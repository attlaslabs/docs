As chaves de API do Workspace permitem que ferramentas de desenvolvimento externas e assistentes de IA (Claude Code, Cursor, Claude Desktop, VS Code e Codex) conectem-se a todo o seu workspace do Attlas usando o Model Context Protocol (MCP).

O Attlas disponibiliza 55 ferramentas no total em seu workspace: 26 ferramentas de leitura, 24 de escrita e 5 de exclusão. Diferente do endpoint MCP público de chat, as chaves de API do Workspace são credenciais privadas e com escopo que cobrem todos os chats, documentos de conhecimento, gatilhos, contatos e análises do seu workspace.

<Tip>
  Seu assistente já sabe como configurar e aprimorar um chat do Attlas. Pergunte "ajude-me a configurar meu chat" ou "o que devo adicionar ao meu chat de vendas" e ele te guiará passo a passo. Nada para instalar.
</Tip>

<Info>
Você pode fazer o mesmo a partir do dashboard com o [Agente integrado](/pt/basic/agent)
</Info>

## Início rápido

Conecte seu assistente de IA ao seu workspace do Attlas em três etapas:

<Steps>
  <Step title="Crie uma chave de API">
    1. No painel do Attlas, abra **Configurações do workspace**.
    2. Vá para a aba **Chaves de API** (ou **MCP**).
    3. Clique em **Criar chave de API**.
    4. Insira um nome (por exemplo, `Cursor assistant` ou `Claude Code`).
    5. Escolha as permissões (**Write** para criar e editar recursos, ou **Delete** se precisar de privilégios de exclusão).
    6. Clique em **Criar chave** e copie sua chave secreta (`atk_...`) imediatamente.

    <Warning>
      Sua chave de API é exibida apenas uma vez. Armazene-a com segurança. O Attlas não pode exibir a chave secreta novamente depois que o diálogo for fechado.
    </Warning>
  </Step>

  <Step title="Configure seu cliente de IA">
    O endpoint MCP do Workspace está hospedado em:
    ```text
    https://mcp.attlas.so
    ```

    Selecione sua ferramenta de IA abaixo para copiar o comando de configuração ou arquivo de configuração:

    <CodeGroup>

    ```bash Claude Code
    claude mcp add attlas --transport http https://mcp.attlas.so \
      --header "Authorization: Bearer atk_your_api_key"
    ```

    ```json Cursor
    {
      "mcpServers": {
        "attlas": {
          "url": "https://mcp.attlas.so",
          "headers": {
            "Authorization": "Bearer atk_your_api_key"
          }
        }
      }
    }
    ```

    ```json Claude Desktop
    {
      "mcpServers": {
        "attlas": {
          "command": "npx",
          "args": [
            "mcp-remote",
            "https://mcp.attlas.so",
            "--header",
            "Authorization: Bearer atk_your_api_key"
          ]
        }
      }
    }
    ```

    ```json VS Code
    {
      "servers": {
        "attlas": {
          "type": "http",
          "url": "https://mcp.attlas.so",
          "headers": {
            "Authorization": "Bearer atk_your_api_key"
          }
        }
      }
    }
    ```

    ```toml Codex
    [mcp_servers.attlas]
    command = "npx"
    args = [
      "mcp-remote",
      "https://mcp.attlas.so",
      "--header",
      "Authorization: Bearer atk_your_api_key"
    ]
    ```

    </CodeGroup>

    <Tip>
      Se você usa o **Cursor**, clique no botão **Adicionar ao Cursor** diretamente na aba de chaves de API do Attlas para configurar a conexão com um único clique.
    </Tip>
  </Step>

  <Step title="Verifique a conexão">
    Teste sua configuração perguntando ao seu assistente:
    ```text
    List my Attlas chats
    ```
    Seu assistente chamará a ferramenta `list_chats` e retornará a lista de chats com seus identificadores numéricos.
  </Step>
</Steps>

## Claude web e desktop (conector personalizado)

Para conectar a partir do claude.ai ou do aplicativo Claude Desktop, adicione o Attlas como um **conector personalizado**. O endpoint do Workspace se autentica com uma chave de API, não com OAuth, então alguns campos precisam de valores específicos.

<Steps>
  <Step title="Abra o diálogo de conector personalizado">
    No Claude, vá para **Configurações → Conectores → Adicionar conector personalizado** (Team e Enterprise: **Configurações da organização → Conectores → Adicionar → Personalizado**).
  </Step>
  <Step title="Insira a URL">
    ```text
    https://mcp.attlas.so
    ```
  </Step>
  <Step title="Defina Autenticação como Nenhuma">
    Após continuar, o Claude faz uma sondagem da URL e pode pré-selecionar **Sempre obrigatório**, marcado como *Detectado*. Isso é um falso positivo: o servidor retorna `401` para a sondagem não autenticada, e o Claude interpreta isso como OAuth.

    Selecione **Nenhuma** em vez disso. A descrição dessa opção diz explicitamente: *"ou para servidores que usam uma chave de API em vez de OAuth."* A seção **Cliente OAuth** desaparece.
  </Step>
  <Step title="Adicione a chave como um cabeçalho de requisição">
    Abra **Cabeçalhos de requisição** e adicione um cabeçalho:

    | Campo | Valor |
    | --- | --- |
    | Nome | `authorization` (escolha na lista; minúsculas são aceitáveis, nomes de cabeçalho HTTP não diferenciam maiúsculas/minúsculas) |
    | Valor | `Bearer atk_your_api_key` |
    | Obrigatório | marcado |

    <Warning>
      Digite o valor **exatamente** como o servidor espera, incluindo a palavra `Bearer` e um espaço antes da chave. O Claude envia o valor literalmente e não adiciona nenhum esquema. `atk_...` sozinho é enviado como `Authorization: atk_...` e o servidor rejeita com `401`.
    </Warning>
  </Step>
  <Step title="Adicione o conector">
    Clique em **Adicionar** e, em seguida, habilite o Attlas a partir do menu **+** em uma conversa.
  </Step>
</Steps>

<Note>
  **Request headers** é um recurso beta disponível para um conjunto limitado de organizações. Se você não vir essa seção, conecte-se com Claude Code ou `mcp-remote` em vez disso (veja [Início rápido](#quickstart) acima).
</Note>

### Solução de problemas

| Sintoma | Causa | Solução |
| --- | --- | --- |
| A conexão falha, o Claude pede para fazer login com OAuth | Autenticação deixada em **Sempre obrigatório** ou o valor do cabeçalho está sem o prefixo `Bearer ` | Remova o conector e adicione novamente com **Nenhuma** e um valor correto de `Bearer atk_...` |
| `401` em todas as chamadas | Chave incorreta, revogada ou malformada; valor enviado sem `Bearer ` | Verifique a chave na aba **Chaves de API** do Attlas; adicione o conector novamente com o valor exato |
| Ferramentas não aparecem após a conexão | O escopo da chave não as inclui | Crie uma chave com escopo **Write** ou **Delete** |
| Funciona no Claude Code, mas não no claude.ai | O beta de cabeçalhos de requisição não está habilitado para sua organização | Use o Claude Code ou `mcp-remote`, ou entre em contato com o suporte do Claude para solicitar acesso |

## Escopos de permissão

Ao criar uma chave de API, selecione as permissões que correspondem ao seu caso de uso:

| Escopo | Rótulo na interface | O que pode fazer |
| --- | --- | --- |
| `read` | **Leitura** | Visualizar e pesquisar chats, documentos, gatilhos, contatos, conversas e análises. Incluído por padrão em todas as chaves. |
| `write` | **Escrita** | Criar e atualizar documentos, correções, gatilhos, contatos, branding, avatar, SEO e configurações do chat. Inclui automaticamente as permissões de Leitura. |
| `destructive` | **Exclusão** | Excluir permanentemente chats, documentos, gatilhos, contatos e conversas. Inclui automaticamente as permissões de Escrita e Leitura. |

<Warning>
  Conceda a permissão de **Exclusão** apenas a fluxos de trabalho confiáveis onde a limpeza automatizada ou a exclusão de recursos seja explicitamente necessária.
</Warning>

## Requisitos de plano

O servidor MCP do workspace funciona em todos os planos. Algumas ações seguem os mesmos limites de plano do painel:

| Ação | Requisito |
| --- | --- |
| Criar um chat (`create_chat`) | Usa um chat da cota do seu plano. Retorna `quota_exceeded` quando não há mais nenhum. |
| Ler métricas, tendências, rankings ou gerar um relatório | O intervalo retorna apenas até o período de histórico do seu plano (Gratuito: 90 dias, Starter: 1 ano, PRO: 2 anos). Intervalos maiores são limitados a essa janela. |
| Adicionar um link de vídeo do YouTube, Instagram, TikTok, Facebook ou X, ou um arquivo de áudio, a uma base de conhecimento | Starter ou PRO. Links de páginas da web funcionam em todos os planos. |
| Remover o selo de branding do Attlas (`update_branding`) | Complemento de marca. |
| Personalizar metadados de SEO do chat (`update_seo`) | Starter ou PRO. |
| Editar as configurações de banco de dados SQL conectado de um chat | Starter ou PRO. |
| Código de incorporação de balão ou popup (`get_embed_code`) | Plano PRO. A incorporação padrão via iframe funciona em todos os planos. |

<Tip>
  Seu assistente pode chamar `can_use` para verificar se uma ação é permitida pelo seu plano, e `get_usage` para ver seus chats, mensagens e caracteres restantes.
</Tip>

## Ferramentas disponíveis

O Attlas disponibiliza 55 ferramentas no total. Cada ferramenta precisa do escopo mostrado ao lado, e uma chave só vê as ferramentas que seu escopo permite.

### Chats e configuração

| Ferramenta | Escopo | O que faz |
| --- | --- | --- |
| `list_chats` | Read | Lista seus chats com seus ids. Seu assistente chama primeiro. |
| `get_chat_overview` | Read | Tudo sobre um chat em uma única leitura, além de uma lista classificada do que está faltando. |
| `get_chat_config` | Read | Configurações de um chat: objetivo, captação de leads, integrações, avatar, SEO, informações da empresa. |
| `preview_chat` | Read | Mostra uma prévia ao vivo do chat público. As mensagens enviadas na prévia são gratuitas e não contam nas análises. |
| `get_embed_code` | Read | Gera snippets de incorporação prontos para colar (iframe padrão, botão de balão ou gatilho popup) com rastreamento opcional de canais. |
| `read_skill` | Read | Acessa playbooks de produto e melhores práticas da Attlas (configuração guiada, gatilhos, tema, setores, conhecimento). |
| `read_url_preview` | Read | Obtém metadados públicos e preços de produtos de e-commerce a partir de uma URL antes de criar um gatilho. |
| `read_instagram_profile` | Read | Extrai detalhes do perfil, URL da foto de avatar e links externos a partir de um perfil do Instagram. |
| `read_linkedin` | Read | Extrai detalhes de perfil ou empresa, logotipo, resumo e links do LinkedIn. |
| `list_theme_presets` / `list_archetypes` | Read | Os temas e personalidades que você pode escolher. |
| `create_chat` | Write | Cria um novo chat. |
| `create_channel` | Write | Adiciona um canal de distribuição nomeado (site, bio do Instagram, newsletter) para marcar conversas recebidas. |
| `update_chat` | Write | Nome, descrição, mensagem de boas-vindas e qual aba abre primeiro. |
| `update_activity_profile` | Write | Informações da empresa: site, email, telefone, endereço, horário de funcionamento, empresa ou pessoa. |
| `set_objective` | Write | Suporte, agendamento de consultas ou captação de leads, além de suas próprias instruções. |
| `set_personality` | Write | Tom de voz ou uma personalidade pronta. |
| `update_theme` | Write | Cores e tema visual. |
| `update_avatar` | Write | Avatar a partir de uma URL de imagem ou um emoji. |
| `update_social_links` | Write | A fileira de ícones sociais na parte inferior do chat. |
| `update_seo` | Write | Meta título, meta descrição e imagem de compartilhamento. |
| `update_branding` | Write | Mostra ou oculta o selo 'Powered by Attlas'. |
| `update_database_connection` | Write | Nome, descrição, moeda e ativação/desativação de um banco de dados SQL conectado. As credenciais permanecem intocadas. |

### Conhecimento

| Ferramenta | Escopo | O que faz |
| --- | --- | --- |
| `list_documents` / `read_document` | Read | Lista os documentos de um chat com seus status, ou lê um na íntegra. |
| `create_document` | Write | Adiciona um documento de texto. |
| `ingest_url` | Write | Adiciona uma página da web, um link de arquivo ou um vídeo (YouTube, TikTok, Instagram, X). |
| `update_document` | Write | Edita um documento de texto. Apenas a diferença no comprimento conta contra sua cota. |
| `clean_document` | Write | Reformata um documento importado bagunçado. |
| `create_correction` | Write | Ensina ao chat a resposta certa para uma pergunta que ele errou. |

<Info>
  Adicionar ou editar conhecimento leva um instante. Essas ferramentas respondem imediatamente com um status `processing`, e seu assistente verifica `list_documents` até que o documento esteja pronto.
</Info>

### Gatilhos

| Ferramenta | Escopo | O que faz |
| --- | --- | --- |
| `list_triggers` | Read | Lista botões, links, mídia, produtos e perguntas de um chat. |
| `create_trigger` / `update_trigger` | Write | Adiciona ou edita um gatilho. |
| `reorder_triggers` | Write | Altera a ordem e o aninhamento. |
| `generate_questions` | Write | Sugere perguntas de visitantes a partir de seus documentos, sem criar nada. |
| `generate_and_nest` | Write | Gera perguntas e as coloca sob um gatilho em uma única etapa. |

### Contatos e agendamentos

| Ferramenta | Escopo | O que faz |
| --- | --- | --- |
| `list_contacts` | Read | Lista os contatos capturados por seus chats, com seu estágio. |
| `list_appointments` | Read | Lista os agendamentos realizados. |
| `update_contact` | Write | Altera o estágio de um contato ou notas internas. |

### Insights

| Ferramenta | Escopo | O que faz |
| --- | --- | --- |
| `get_metrics` | Read | Mensagens, visualizações, cliques, leads, conversão e cobertura de conhecimento, comparados ao período anterior. |
| `get_timeseries` / `get_rankings` | Read | Atividade ao longo do tempo, e principais gatilhos, países, dispositivos e canais. |
| `list_signals` | Read | Perguntas que seu chat não conseguiu responder, respostas negativadas e visitantes que saíram. |
| `list_conversations` / `read_conversation` | Read | Conversas de visitantes e suas mensagens. |
| `list_reports` / `read_report` | Read | Relatórios já gerados. |
| `generate_report` | Write | Escreve um relatório de análise para um período. |

### Plano

| Ferramenta | Escopo | O que faz |
| --- | --- | --- |
| `get_usage` | Read | Seu plano e chats, mensagens e caracteres restantes. |
| `can_use` | Read | Verifica se seu plano permite uma ação. |

### Excluir

| Ferramenta | Escopo | O que faz |
| --- | --- | --- |
| `delete_chat` | Delete | Exclui um chat e tudo nele. Permanente. |
| `delete_document` | Delete | Exclui um documento e devolve seus caracteres. Permanente. |
| `delete_trigger` / `delete_contact` | Delete | Move um gatilho ou contato para a lixeira por 30 dias. |
| `delete_conversation` | Delete | Oculta uma conversa em todos os lugares. Você não pode restaurá-la via MCP. |

## O que permanece no painel

Algumas configurações precisam que você esteja em [attlas.so](https://attlas.so). Seu assistente informa quando uma solicitação se enquadra aqui:

- Alterar a URL de um chat.
- Conectar uma integração: Google Calendar, Notion, um banco de dados SQL, Bandsintown, a API de Conversões da Meta, um domínio personalizado ou um webhook. Uma vez conectado, seu assistente pode configurá-lo e usá-lo.
- Modo de acesso, senha e visibilidade pública ou privada.
- Plano, faturamento e complementos.
- Membros do Workspace e convites.

## Monitoramento de atividade e logs de auditoria

A tabela **Recent activity** na parte inferior da aba de chaves de API registra cada chamada MCP feita ao seu espaço de trabalho:

- **When**: Timestamp relativo da solicitação.
- **Key**: Prefixo da chave usada (`atk_...`).
- **Tool**: A ferramenta MCP chamada (ex. `list_chats`, `create_document`, `delete_trigger`).
- **Target**: O recurso afetado pela operação.
- **Result**: Selo de sucesso (`ok`) ou erro.

Ative **Changes only** para ocultar chamadas de leitura.

### Restaurar itens excluídos

Se uma ferramenta excluir acidentalmente um gatilho ou contato por engano, clique em **Restaurar** na linha de atividade para trazê-lo de volta ao seu workspace imediatamente.
